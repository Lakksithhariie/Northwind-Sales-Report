# 📊 Northwind Traders | Sales Report

## Overview

This Power BI dashboard analyzes Northwind Traders' sales performance, providing key insights into total revenue, order trends, and top-selling products. 
![Sales Report](https://github.com/user-attachments/assets/1564577d-7d6f-4365-a087-2b7fa578831c)


## 📌 Key Metrics:
- **Total Sales:** $1.33M
- **Total Orders:** 2,082
- **Average Order Value:** $637
- **Top Products & Customers**
- **Sales Breakdown by Country & Region**
- **Monthly Sales Trend Analysis**

## 🗂 Data Source

This report is built using the **Northwind OData API**, which provides structured sales data:
🔗 [Northwind OData Service](https://services.odata.org/v2/northwind/northwind.svc)

## 📊 Dashboard Features

1. **Sales Summary:** High-level KPIs for revenue, orders, and AOV.
2. **Monthly Sales Trend:** Time-series analysis of order trends.
3. **Sales by Country:** Geographic breakdown of total sales.
4. **Top Customers & Products:** Identifies high-value clients and best-selling items.

## ⚙️ How to Use

1. **Open in Power BI:** Download and open the `.pbix` file.
2. **Connect to Data:**
   - Go to **Transform Data** → **Data Source Settings**.
   - Replace the Northwind OData URL if needed.
3. **Refresh Data:** Click **Refresh** to load the latest sales data.
4. **Explore Insights:** Use slicers and filters for deeper analysis.
